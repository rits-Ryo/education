# 電場と電位

高校物理の静電場。3次元点電荷の場を平面断面に描き、電場ベクトル・電気力線・必須の等電位線・電位色分布を重ねます。

## 操作

2個までの電荷（qはnC、位置m）とPをドラッグ・矢印キー・数値入力で移動できます。q、位置、表示半幅をスライダーと数値入力で操作。単独＋、単独−、双極子、同符号2電荷のプリセット、表示切替、寄与表示、初期状態へのリセットがあります。単独のプリセットではq₂ = 0として無効にします。電荷の位置がほぼ重なるとドラッグハンドルを左右にずらして識別します。表示範囲外の点は通知し、座標入力や半幅変更で戻せます。

## 物理モデル

真空・静電場・点電荷・線形の重ね合わせ。k = 8.9875517923e9 N·m²/C²、1 nC = 1e-9 C。E = ΣkqR/r³ N/C、V = Σkq/r V（無限遠0）。2次元独自の1/r電場ではありません。導体・誘電体境界・時間変化は対象外。試験電荷は計算に追加しません。

中心r = 0は未定義、活動中の重なった電荷中心も未定義にします。q = 0の電荷は場を作りません。半径0.12 mの除外円は描画だけで、Pが中心以外なら元の式で数値を計算します。有限値に置き換える正則化は行いません。極端に中心へ近い入力などでNumberの表現範囲を超えた場合は、中心の特異点とは区別して数値表示不可とします。

## 描画近似

電気力線は正規化Eを4次Runge–Kuttaで追跡（刻みはmin(0.05 m, 表示半幅/150)、上限800ステップ）。境界・除外円・零電場、または合成電場が各寄与の大きさの合計の1e-10未満の点で停止します。負電荷のみの場合は逆向きに追跡し矢印をE方向に配置。各電荷から12本の概念的な種を使い、本数が電場強度を厳密に表すとはしません。

等電位線はMarching Squaresの格子近似（小画面64分割、その他96分割）、値は−20, −10, −5, −2, 0, 2, 5, 10, 20 V。曖昧な4交点セルは中心電位で接続し、特異／除外セルを省略。色域は±20 V、格子矢印長は対数圧縮し32px以下、力線の矢印長は固定です。どれも計算値をクリップしません。配置・表示が不変の間は静的層を再利用します。E ≠ 0で等電位線とEは局所的に直交し、E = 0の特殊点では向きを一意に定めません。
