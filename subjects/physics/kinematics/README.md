# 等加速度直線運動

高校物理基礎の1次元運動。x-t、v-t、a-tの同期、接線・傾き補助線、符号付き面積を扱います。

## 操作

x₀、v₀、a、観察時間T、時刻t、区間端点t₁・t₂をスライダーまたは数値入力で変更します。t₁ ≤ t₂が必要です。時刻の再生はTで停止し、速度倍率を変更できます。リセットは時刻を0に戻します。等速・静止・自由落下・投げ上げプリセットと接線／面積表示切替があります。Tを縮めると時刻・区間端点を新しいT以下に収めます。

## 物理モデル

x = x₀ + v₀t + at²/2、v = v₀ + at、a一定。通常は右向き正。鉛直プリセットは上向き正で、画面の右側が正座標に対応します。g = 9.80665 m/s²、地面衝突・空気抵抗なし。2次元投射は対象外です。変位はv-tの符号付き台形面積で、移動距離は速度の零点で分けて絶対値を加えます。速度変化はa-tの面積です。微小区間の変位は位置同士の減算による桁落ちを避ける台形公式で計算します。
