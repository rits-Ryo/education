等加速度直線運動

位置・速度・加速度と、傾き・符号付き面積を同じ時刻で見る。

運動と3つのグラフ

右向きを正、時刻\(t \ge 0\)とします。

\(x-t\)：位置と接線

\(v-t\)：速度と符号付き面積

\(a-t\)：加速度と符号付き面積

結果は最大3桁の近似表示。計算・入力は丸めません。速度は青、加速度は赤で示します。速度0でも加速度は0とは限りません。

1. 位置・変位と時刻

位置\(x\)は原点からの符号付き座標です。変位\(\Delta x = x(t_{2}) - x(t_{1})\)は位置の変化で、移動距離は実際に進んだ長さの合計です。速度の符号が反転すると、正負の変位は相殺されても移動距離は加算されます。

2. 速度と\(x-t\)の傾き

\[\begin{aligned}x(t)&=x_0+v_0t+\frac12at^2\\v(t)&=v_0+at\end{aligned}\]

\(x-t\)の接線の傾き\(\frac{dx}{dt}\)がその時刻の速度\(v\)です。速度\(v\)は向きを含み、速さは|\(v|\)です。\(v\)が負なら負方向、\(v = 0\)ならその瞬間の位置変化率は0です。

3. 加速度と\(v-t\)の傾き

\[a=\frac{dv}{dt}=\text{一定}\]

加速度は速度の変化率です。加速度が負でも速さが常に減るわけではありません。\(v\)と\(a\)が同じ符号なら速さが増え、異符号なら速さが減ります。折り返しで\(v = 0\)でも\(a \ne 0\)になり得ます。

4. グラフの面積と変化量

\[\begin{aligned}\Delta x&=\int_{t_1}^{t_2}v(t)\,dt\\&=\frac{v(t_1)+v(t_2)}2(t_2-t_1)\\\Delta v&=\int_{t_1}^{t_2}a\,dt=a(t_2-t_1)\end{aligned}\]

∫は区間の小さな量を足し合わせる記号です。\(v-t\)の時間軸より上は正、下は負の面積として変位を求めます。移動距離は\(v = 0\)で区間を分割し、各面積の絶対値を加えます。\(a-t\)の符号付き面積は速度変化で、単位は\(\frac{m}{s}\)です。

5. 等加速度の3公式と適用条件

\[\begin{aligned}v&=v_0+at\\x-x_0&=v_0t+\frac12at^2\\v^2-v_0^2&=2a(x-x_0)\end{aligned}\]

1次元で加速度が一定の区間に適用します。自由落下・投げ上げでは上向きを正に\(a = -g\)、\(g = 9.80665 \frac{\mathrm m}{\mathrm s^{2}}\)とします。地面衝突・空気抵抗は扱わず、位置が負になっても理想運動を続けます。画面上の軸は座標の正方向を右に配置し、鉛直プリセットでは右側が上向きの座標に対応します。
