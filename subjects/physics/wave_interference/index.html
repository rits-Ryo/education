波の重ね合わせと干渉

経路差・位相差・合成振幅を、平面の波と観測点の時間波形で結ぶ。

2つの波源と観測点

青：\(S_{1} / u_{1}\)赤：\(S_{2} / u_{2}\)紫：合成\(u\)

観測点\(P\)の時間–変位波形

\(P\)をドラッグ、または選択して矢印キーで移動。\(x\)は右、\(y\)は上が正。\(\lambda \)と\(f\)は独立入力、速さ\(v = f\lambda \)は連動します。波源位置は間隔\(d\)で変更します。結果は最大3桁の近似表示です。

1. 進行波と波の速さ

\[v=f\lambda,\quad T=\frac1f,\quad\omega=2\pi f,\quad k=\frac{2\pi}{\lambda}\]

\(\lambda \)は同じ位相の隣り合う波面の距離、\(f\)は1秒あたりの振動回数です。一定の位相の波面は各波源から外側に速さ\(v\)で進みます。距離は\(m\)、時間は\(s\)、変位と振幅は\(cm\)です。

2. 重ね合わせ

\[\begin{aligned}u_1(P,t)&=A\sin(\omega t-kr_1+\varphi_1)\\u_2(P,t)&=A\sin(\omega t-kr_2+\varphi_2)\\u&=u_1+u_2\end{aligned}\]

同じ媒質の同振動数で位相関係が保たれるコヒーレントな2波源です。\(\varphi _{2} = 0\)とし、操作する位相差は\(\varphi _{1} - \varphi _{2}\)です。ある瞬間の変位は各波の変位の和で、振幅は振動の最大の大きさです。色は変位または振幅を示し、エネルギー・強度を示しません。

3. 経路差と位相差

\[\begin{aligned}\Delta r&=r_2-r_1\\\Delta&=k(r_2-r_1)+(\varphi_1-\varphi_2)\\\text{強め合い：}\Delta&=2m\pi\\\text{弱め合い：}\Delta&=(2m+1)\pi\quad(m\in\mathbb Z)\end{aligned}\]

\(\Delta \)は観測点での第1波の位相から第2波の位相を引いた値です。同位相の波源では|\(\Delta r| = m\lambda \)（\(m = 0, 1\), …）で強め合い、|\(\Delta r| = (m +\) ½)\(\lambda \)で弱め合います。波源に位相差がある場合も上の\(\Delta \)の条件で判定します。経路差は|\(\Delta r| \le d\)を満たすため、代表状態では\(\lambda = 2 m\)、\(d = 4 m\)の実現可能な配置を使います。

4. 時間波形と合成振幅

\[B=2A\left|\cos\frac\Delta2\right|\]

時間波形の紫の振動の最大の大きさが\(B\)です。瞬間的に\(u = 0\)でも\(B \ne 0\)ならその点は振動します。\(B = 0\)の位置は全時刻で打ち消し合う節です。画面の条件表示は位相に1×10⁻¹⁰ \(rad\)の数値許容差を用い、近傍の帯は条件そのものと区別します。

5. 干渉縞と理想モデル

経路差と位相差が一定の場所に干渉の帯が現れます。黒の帯は強め合いの近傍、白の帯は弱め合いの近傍です。モデルは無限に続く正弦波の定常状態で、振幅の距離減衰、反射、境界効果、波の到着前の領域を扱いません。水面波の完全な現実再現ではありません。点波源中心でも距離0の位相式を使用し、発散する振幅を仮定しません。
