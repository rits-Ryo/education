# 波の重ね合わせと干渉

高校物理の2つのコヒーレントな同振動数点波源。平面の合成変位／振幅分布とPの時間波形を連動させます。

## 操作

λ、f、A、φ₁−φ₂、波源間隔d、時刻を変更します。λとfは独立でv = fλを連動表示します。Pはドラッグ・矢印キー・座標入力で移動。再生・停止・初期状態へのリセット、速度倍率、近傍の干渉帯、変位／振幅マップ切替があります。時間範囲は4周期、f変更時には現在時刻を範囲内へ収めます。プリセットはλ = 2 m、d = 4 mで経路差0、λ/2、λを確実に実現します。

## モデル・符号と単位

φ₂ = 0、φ₁ = 入力位相差。uᵢ = A sin(ωt − krᵢ + φᵢ)、Δ = k(r₂−r₁)+(φ₁−φ₂)、B = 2A|cos(Δ/2)|です。時間s、距離m、変位・振幅cm。同位相条件はΔ = 2mπ、逆の条件はΔ = (2m+1)π（m整数）。瞬間のu = 0とB = 0は異なります。位相条件の文字表示には1e-10 radの数値許容差を明記し、Bの微小非零値は指数表記で保持します。

定常の正弦波、距離減衰・反射・境界・到着前の波面を扱わない理想モデルで、現実の水面波や強度の再現ではありません。波源中心では距離0の正弦波を使います。黒い帯はB/(2A) > 0.995、白い帯は < 0.06の近傍表示で、厳密な節／腹の線そのものではありません。A = 0では帯を表示しません。

## 描画と検証

Canvasは小画面120×90、その他180×135の格子から滑らかに表示。波面の位相・振幅をキャッシュし、再生は小画面約20fps、その他約30fpsを上限にします。各波源の山の等位相波面はSVGの円、観測点の波形はSVGです。SVG/CSSはレスポンシブですが実端末の性能確認は別途必要です。
