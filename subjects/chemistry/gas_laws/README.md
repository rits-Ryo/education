# 気体の状態方程式と気体法則

化学 · 気体。`index.html`を化学カタログから開きます。固定条件を選び、物質量・体積または圧力・温度を変更します。再生は粒子模型だけを動かします。

## モデル・仮定・例外

理想気体ではPをPa、Vをm³、TをKにそろえて状態方程式を使います。ボイルはn・T一定の双曲線、シャルルはn・P一定の直線、圧力と温度の法則はn・V一定の直線です。入力した変数から残る量を計算するため、独立でない値を同時に固定しません。1 mol、273.15 K、22.414 Lなら約101.325 kPaです。0 K以下は拒否します。低圧・高温に近い理想化で、凝縮や実在気体の補正は含めません。粒子の表示数はnを固定して保ち、模式速度を√Tに対応させます。混合気体では理想気体近似で全圧は分圧の和です。

PV=nRT,\quad R=8.314462618\ldots\,\mathrm{J\,mol^{-1}\,K^{-1}} / T[\mathrm K]=t[{}^\circ\mathrm C]+273.15

データ・出典：教科書範囲の関係式による教育用モデル。実測データではありません。

模式図は実測画像や実験手順ではありません。入力は表示目的で丸めず、有限値・範囲を検証します。無効入力では直前の有効な状態を保ちます。表示は既存NumberDisplayの最大3桁と指数表記、数式は標準KaTeX 0.19.0（新しい拡張・CDNなし）です。

## 構成・検証・改良箇所

engine.jsはDOM非依存の計算とローカルデータ、tests.jsは化学・物質収支・境界の独立検証、drawing.jsは教材固有のSVG、script.jsは状態と操作です。説明・表示の変更はindex.html/style.css、数値モデルの変更はengine.js/tests.js、ラベルと図形の調整はdrawing.jsから行います。化学教材の入力・SVG基本部品のみ../shared/を再利用します。既存数学・物理を変更しません。

ルートで `node subjects/chemistry/gas_laws/tests.js`、全体は `python3 scripts/verify.py`。安全なプレビューと未追跡ファイルの追加はscripts/README.mdに従います。ブラウザ検証結果は全体の作業報告を参照してください。実機・Safari・Windowsの動作は別途確認が必要です。
