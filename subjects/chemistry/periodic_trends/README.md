# 周期表と元素の周期性

化学基礎 · 周期表。`index.html`を化学カタログから開きます。1〜36番の元素を表または選択欄から選び、比較周期を切り替えます。

## モデル・仮定・例外

周期は電子殻、族は価電子や化学的性質の共通性と関係します。典型元素の価電子数を示し、遷移元素には単純な族番号からの推測値を付けません。Cr・Cuの電子配置の例外も収録します。電気陰性度は結合電子を引き付ける傾向を表す尺度で、ここではPauling尺度の代表値です。未収録・未定義は空欄で示します。原子半径は共有結合半径・金属半径など定義で異なり、イオン化エネルギーは気相原子から電子を除くエネルギーです。定量データのない属性を推測値で埋めません。一般に周期内では半径が減少し電気陰性度が増す傾向、同族下方では半径が増す傾向がありますが、例外があり全元素で単調ではありません。Znはdブロックですが、狭義の遷移元素の定義とは区別します。

\text{価電子：典型元素の最外殻電子（Heは2）}

データ・出典：原子番号・族：IUPAC周期表。電子配置：基底状態の代表配置。Pauling電気陰性度の代表値：Royal Society of Chemistry周期表 https://www.rsc.org/periodic-table （希ガスの欠損は補完しない）。

模式図は実測画像や実験手順ではありません。入力は表示目的で丸めず、有限値・範囲を検証します。無効入力では直前の有効な状態を保ちます。表示は既存NumberDisplayの最大3桁と指数表記、数式は標準KaTeX 0.19.0（新しい拡張・CDNなし）です。
