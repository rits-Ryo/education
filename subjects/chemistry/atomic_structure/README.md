# 原子の構造と電子配置

化学基礎 · 物質の構成。`index.html`を化学カタログから開きます。元素・同位体・電荷を切り替えると粒子数と電子殻が連動します。

## モデル・仮定・例外

原子番号は陽子数、質量数は陽子と中性子の合計です。同じ原子番号で中性子数が異なる原子が同位体です。例：炭素12は陽子6・中性子6、ナトリウムイオンNa⁺は電子10です。収録する質量数は代表同位体だけで、放射性のものも含み、全同位体や安定性を示す一覧ではありません。電子殻は高校向け概念図で、電子が惑星のような固定軌道を周回する事実描写ではありません。表示可能な電荷を基本的なイオンに限定しています。

Z=p,\qquad A=p+n,\qquad q/e=p-N_e

データ・出典：H〜Caの代表同位体・基本的なイオン。IUPAC周期表の原子番号に基づく高校向け殻模型。

模式図は実測画像や実験手順ではありません。入力は表示目的で丸めず、有限値・範囲を検証します。無効入力では直前の有効な状態を保ちます。表示は既存NumberDisplayの最大3桁と指数表記、数式は標準KaTeX 0.19.0（新しい拡張・CDNなし）です。

## 構成・検証・改良箇所

engine.jsはDOM非依存の計算とローカルデータ、tests.jsは化学・物質収支・境界の独立検証、drawing.jsは教材固有のSVG、script.jsは状態と操作です。説明・表示の変更はindex.html/style.css、数値モデルの変更はengine.js/tests.js、ラベルと図形の調整はdrawing.jsから行います。化学教材の入力・SVG基本部品のみ../shared/を再利用します。既存数学・物理を変更しません。

ルートで `node subjects/chemistry/atomic_structure/tests.js`、全体は `python3 scripts/verify.py`。安全なプレビューと未追跡ファイルの追加はscripts/README.mdに従います。ブラウザ検証結果は全体の作業報告を参照してください。実機・Safari・Windowsの動作は別途確認が必要です。
