# 状態変化・相図・蒸気圧

化学基礎・化学 · 状態。`index.html`を化学カタログから開きます。熱量と相図の温度・圧力を変更します。加熱の停滞区間と、平衡の相領域を別パネルで表示します。

## モデル・仮定・例外

一定圧力・純物質の単純化した加熱曲線です。相変化中は潜熱に熱量を使うため温度が一定になります。実際の測定値ではなく、融点0・沸点100を設定した教育用の架空の純物質です。相図は別の平衡状態パネルで、点の温度・圧力を変更します。相境界では共存可能、三重点では3相共存として表示します。現実の水では固液境界が特殊な負の傾きを持ち、この模型の正の傾きとは異なります。蒸気圧曲線は温度と物質に依存し、この図の指数曲線は根拠のない精密実測値ではありません。加熱曲線と相図の点は別条件です。

Q=mc\Delta T\quad\text{（単相）},\qquad Q=mL\quad\text{（相変化）}

データ・出典：教科書範囲の関係式による教育用モデル。実測データではありません。

模式図は実測画像や実験手順ではありません。入力は表示目的で丸めず、有限値・範囲を検証します。無効入力では直前の有効な状態を保ちます。表示は既存NumberDisplayの最大3桁と指数表記、数式は標準KaTeX 0.19.0（新しい拡張・CDNなし）です。

## 構成・検証・改良箇所

engine.jsはDOM非依存の計算とローカルデータ、tests.jsは化学・物質収支・境界の独立検証、drawing.jsは教材固有のSVG、script.jsは状態と操作です。説明・表示の変更はindex.html/style.css、数値モデルの変更はengine.js/tests.js、ラベルと図形の調整はdrawing.jsから行います。化学教材の入力・SVG基本部品のみ../shared/を再利用します。既存数学・物理を変更しません。

ルートで `node subjects/chemistry/phase_diagram/tests.js`、全体は `python3 scripts/verify.py`。安全なプレビューと未追跡ファイルの追加はscripts/README.mdに従います。ブラウザ検証結果は全体の作業報告を参照してください。実機・Safari・Windowsの動作は別途確認が必要です。
