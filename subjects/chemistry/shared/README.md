# 化学教材内の小さな共通部品

ui.jsは入力・リセット・再生停止・視点操作・既存MathDisplayの呼び出しだけを共有します。drawing.jsはSVGの座標変換・軸・容器・粒子・投影の基本部品、style.cssはレスポンシブ配置です。化学的な計算・データ・図の意味は各教材のengine.js/drawing.jsに置きます。

動的LaTeXの複数行を区切る際は、次の行が濃度の角括弧で始まっても改行のサイズ指定と誤解されないよう空グループを挟みます。tests.jsは各教材の実際の制御コードの数式生成を固定版KaTeXで検証するNode用ヘルパーです。安全なプレビューはtests.jsを配信しません。

新しいビルド工程・外部API・化学拡張は導入しません。入力は丸めず、計算結果だけ既存NumberDisplayで最大3桁、科学表記の仮数も最大3桁にします。定義定数や厳密な式は各HTMLにそのまま記述します。
