# 溶液の濃度・希釈・混合

化学基礎 · 溶液。`index.html`を化学カタログから開きます。2量からの換算、希釈後体積、同種溶質の2溶液を操作します。

## モデル・仮定・例外

モル濃度は溶質の物質量を溶液全体の体積で割った量です。体積をLにそろえます。希釈では溶質のmolが保存され、溶液体積を増やします。同じ溶質の混合では溶質のmolを足します。体積加成、反応なし、温度による体積変化なしを仮定します。1 Mの100 mLを500 mLまで希釈すると0.2 Mです。質量パーセント濃度には溶液質量が必要で、密度なしにモル濃度と直接換算しません。希釈後体積が希釈前より小さい入力は拒否します。

c=\frac nV,\qquad c_1V_1=c_2V_2 / c_{\rm mix}=\frac{c_1V_1+c_2V_2}{V_1+V_2}

データ・出典：教科書範囲の関係式による教育用モデル。実測データではありません。

模式図は実測画像や実験手順ではありません。入力は表示目的で丸めず、有限値・範囲を検証します。無効入力では直前の有効な状態を保ちます。表示は既存NumberDisplayの最大3桁と指数表記、数式は標準KaTeX 0.19.0（新しい拡張・CDNなし）です。
