# 有機化合物の構造と異性体

化学 · 有機化学。`index.html`を化学カタログから開きます。異性体と構造式/骨格/模型を切り替え、模型の視点を回転します。

## モデル・仮定・例外

構造異性体は同じ分子式で結合のつながり・官能基が異なる化合物です。エタノールとエーテルは同じC₂H₆Oでも性質が異なり、C₃H₆Oのアルデヒドとケトンも例です。立体異性体は別概念で、単結合回転による配座を別の構造異性体と数えません。C=4、O=2、H=1の価数から省略Hを計算し、検証済みグラフだけを使います。自由描画なし。空間図は精密角度ではなく重原子とH数を示す簡易模型、骨格では端点・頂点がCです。

\mathrm{C_4H_{10}}:\ \text{n-ブタン／2-メチルプロパン} / \mathrm{C_2H_6O}:\ \text{エタノール／ジメチルエーテル} / \mathrm{C_3H_6O}:\ \text{プロパナール／プロパノン}

データ・出典：教科書範囲の関係式による教育用モデル。実測データではありません。

模式図は実測画像や実験手順ではありません。入力は表示目的で丸めず、有限値・範囲を検証します。無効入力では直前の有効な状態を保ちます。表示は既存NumberDisplayの最大3桁と指数表記、数式は標準KaTeX 0.19.0（新しい拡張・CDNなし）です。

## 構成・検証・改良箇所

engine.jsはDOM非依存の計算とローカルデータ、tests.jsは化学・物質収支・境界の独立検証、drawing.jsは教材固有のSVG、script.jsは状態と操作です。説明・表示の変更はindex.html/style.css、数値モデルの変更はengine.js/tests.js、ラベルと図形の調整はdrawing.jsから行います。化学教材の入力・SVG基本部品のみ../shared/を再利用します。既存数学・物理を変更しません。

ルートで `node subjects/chemistry/organic_isomerism/tests.js`、全体は `python3 scripts/verify.py`。安全なプレビューと未追跡ファイルの追加はscripts/README.mdに従います。ブラウザ検証結果は全体の作業報告を参照してください。実機・Safari・Windowsの動作は別途確認が必要です。
