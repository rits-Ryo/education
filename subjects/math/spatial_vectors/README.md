# 空間ベクトルと内積・位置関係

数学C · 空間ベクトル。`index.html` を数学カタログから開きます。静的HTML/CSS/Vanilla JavaScriptと既存KaTeX 0.19.0を使用します。追加ビルド・依存はありません。

## 操作と数学的条件

成分を入力してベクトルを変更します。図をドラッグして視点を回転、スライダーでも方位・仰角・拡大率を調整できます。

3Dライブラリを使わない正射影です。仰角は±85度、拡大率0.5〜2。奥行きは描画順と線種で表現します。視点回転による計算値不変を独立テストします。

結果は既存NumberDisplayで小数点以下最大3桁、微小な非零値は指数表記です。内部計算と入力を丸めません。表示の等号・近似記号を区別します。無効入力は説明を表示し、直前の有効な状態を維持します。

## ファイルと改良箇所

- engine.js：DOMを使わない数学ロジック。式や判定の変更はここから。
- tests.js：代表例・境界・未定義・内部精度の独立テスト。
- drawing.js：SVG描画と数学座標変換。ラベル配置・表示範囲の改良はここから。
- script.js：状態・入力・ドラッグ・数式の同期。
- index.html / style.css：説明と教材専用レスポンシブ表示。

ルートで `node subjects/math/spatial_vectors/tests.js`、全体は `python3 scripts/verify.py`。安全なプレビューはルートのscripts/README.mdに従います。実機Safari・iPad等は別途確認してください。

数値表現の範囲外を数学的な零や重解・直交と誤認しないため、極端な係数・座標では明示的に拒否、未定義または範囲外の説明を表示します。
