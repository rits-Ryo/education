# 単位円と三角関数

数学Ⅱの三角関数を、単位円とグラフの連動で説明する教材です。問いかけ・クイズ・学習管理機能は設けていません。

## 起動・操作

VS CodeのLive Serverで `index.html` を開いてください。GitHub Pagesでは数学の教材一覧からアクセスできます。ビルド工程や追加ライブラリは不要です。フォントはサイト共通のGoogle Fonts設定を利用します。

- 単位円の点Pをドラッグ、角度スライダーや数値入力、代表角のボタンで角度を変更します。
- 角度は−720°〜720°に対応し、度数法と弧度法を切り替えられます。ドラッグはマウスとPointer Events対応のタッチ入力を扱います。
- sin・cos・tanは個別に表示できます。横軸は常に弧度法です。表示幅は2π・4π・8πから選べ、表示中心は選んだ角度に追従します。
- 再生ボタンで再生・一時停止・再開します。速度を変更でき、720°に到達すると停止します。角度を手動操作すると再生を停止し、競合を防ぎます。ページを非表示にした場合も停止します。
- 第5章の係数は−5〜5の範囲で変更できます。数値範囲の安定性を保つため、0以外の絶対値は0.000001以上です。cはradです。係数リセットは角度の状態を維持します。

## 構成

- `index.html`：5章の数学的な説明と操作パネル。
- `style.css`：教材専用レイアウト。共通CSSには影響しません。
- `math.js`：角度変換、代表角、象限、関数変形、漸近線の計算。
- `drawing.js`：SVG描画。正方形のviewBoxで円の縦横比を維持します。
- `script.js`：入力・ドラッグ・再生の状態管理と画面更新。
- `tests.js`：Node.jsで実行する数学的な自動テスト。

## 正確性と表示範囲

代表角は分数・根号で表示します。それ以外の計算結果と座標は小数点以下2桁まで表示し、末尾の不要な0を省略します。近似値の記号は「≒」です。入力値・関数式の係数・内部計算の精度は維持します。代表角の認識には弧度法で約1e−12の許容差を用い、軸上の値を0に補正します。未定義点の近くの一般角はtanを計算し、未定義点そのものでは値を表示しません。

tanは漸近線ごとに描画区間を分割します。グラフの縦範囲は−3〜3です。係数変形の縦範囲は値域を含むよう自動調整します。SVGは有限の標本点をつなぐ描画であり、数式自体の計算と区別されます。グラフの拡大操作・任意の範囲入力は設けず、角度幅の選択に対応しています。

## テストと確認方法

```sh
node subjects/math/trigonometric_functions/tests.js
node subjects/math/Quadratic_function/tests.js
```

代表角・負の角度・周期性・象限・tanの未定義点と左右の値・恒等式・変形・係数0・入力の境界を検証します。

ブラウザでは、数学一覧から教材を開き、点Pのドラッグ、数値の直接入力、単位の変更、tanの表示、再生・停止、係数の0と負の値、リセットを確認してください。狭い画面では図が縦に並びます。iPadのSafariではタッチドラッグとページスクロールの分離も確認してください。

今後は描画の標本点を曲率に応じて調整することや、グラフの表示範囲をより自由に設定する機能を追加できます。
