単位円と三角関数

円周上の点の座標が、角度に応じて変わります。

1 定義 2 グラフ 3 弧度法 4 相互関係 5 グラフの変形

1. 単位円と三角関数の定義

原点\(O\)を中心とする半径1の円を単位円といいます。正の\(x\)軸を始線とし、反時計回りを正、時計回りを負として角度\(\theta \)を測ります。角度\(\theta \)の動径と円との交点を\(P\)とすると、\(P\)の\(x\)座標を\(\cos \theta \)、\(y\)座標を\(\sin \theta \)と定義します。

\[P=(\cos\theta,\sin\theta)\]

点\(P\)をドラッグすると角度が変わります。円をまたいで回すと周回数も保たれます。

図の破線は各座標軸への射影です。\(x\)座標は左右の位置、\(y\)座標は上下の位置を表し、左側と下側では負になります。軸上の点は象限に含めません。

2. 単位円と三角関数のグラフ

横軸\(x\)は角度（弧度法）、縦軸\(y\)は関数値です。同じ\(\theta \)に対して、単位円の\(y\)座標が\(\sin \)のグラフの高さ、\(x\)座標が\(\cos \)のグラフの高さになります。以下の単位円は第1章と同じ角度で動きます。

\(\sin x\)と\(\cos x\)の基本周期（最小の正の周期）は2\(\pi \)です。どちらも最大値1、最小値−1を取り、\(\sin (-x) = -\sin x\) は原点対称、\(\cos (-x) = \cos x\) は\(y\)軸対称を表します。\(\sin x = \cos (x - \frac{\pi }{2})\) なので、両者は横方向に\(\frac{\pi }{2}\)ずれた形です。

\(\tan x = \frac{\\sin x}{\\cos x}\) は \(x = \frac{\pi }{2} + k\pi \)（\(k\)は整数）では定義されません。その位置に縦の漸近線を描き、左右のグラフはつなぎません。基本周期は\(\pi \)で、\(\tan (-x) = -\tan x\) です。値は上下に限りなく大きくなり、最大値・最小値はありません。

3. 弧度法と周期性

半径\(r\)の円で長さ\(\ell \)の円弧に対応する中心角の大きさを、\(\frac{\ell }{r} rad\)と定めます。したがって \(\ell = r|\theta |\) です。単位円では、回転してたどった弧の長さは |\(\theta |\) になります。負の角度でも長さは負にならず、回転の向きだけが逆になります。

\[180^\circ=\pi\,\mathrm{rad},\qquad360^\circ=2\pi\,\mathrm{rad}\]

\[\text{弧度法}=\text{度数法}\times\frac\pi{180}\]

1周を超える角度や負の角度も一般角として扱います。\(\theta \)と\(\theta + 2k\pi \)は同じ円周上の点を表します。図の色付きの弧は、整数回の回転を除いた残りの回転です。たどった全長と周回数は上の数値に示しています。

\[\begin{aligned}\sin(\theta+2k\pi)&=\sin\theta\\\cos(\theta+2k\pi)&=\cos\theta\end{aligned}\]

\(\theta + \pi \)では点\(P\)が原点の反対側に移り、\(\sin \)と\(\cos \)の符号が両方変わります。その比\(\tan \)は変わらないため、\(\tan (\theta + k\pi ) = \tan \theta \) が成り立ちます（定義される角度に限ります）。

4. 三角関数の相互関係

\[\sin^2\theta+\cos^2\theta=1\]

\(P\)から\(x\)軸に垂線を下ろし、その足を\(H\)とします。直角三角形OHPの辺の長さは |\(\cos \theta |\)、|\(\sin \theta |\)、1です。三平方の定理から \(\cos ^{2}\theta + \sin ^{2}\theta = 1\) が得られます。\(P\)が軸上にある場合も、単位円の方程式 \(x^{2} + y^{2} = 1\) により成立します。

\[\tan\theta=\frac{\sin\theta}{\cos\theta}\quad(\cos\theta\ne0)\]

第1象限の鋭角では、直角三角形の「対辺/隣辺」が\(\frac{\\sin \theta }{\\cos \theta }\)に一致します。一般角でもこの座標の比で\(\tan \)を定義します。図の直線\(OP\)の傾きがその比を表します。\(\cos \theta = 0\) では分母が0になり、\(\tan \theta \)は定義されません。

5. 三角関数のグラフの変形

\[\begin{aligned}y&=a\sin(bx+c)+d\\y&=a\cos(bx+c)+d\end{aligned}\]

係数は−5〜5。0以外の絶対値は0.000001以上です。\(c\)の単位は\(rad\)です。

灰色の破線は \(y = \sin x\) または \(y = \cos x\)、紫の実線は変形したグラフです。横軸は−2\(\pi \)から2\(\pi \)です。

\(a \ne 0\)、\(b \ne 0\) のとき、中心線\(y = d\)からの振れ幅（振幅）は |\(a|\)、基本周期は 2\(\pi /|b|\) です。\(bx + c = b(x - (-\frac{c}{b}))\) と変形できるため、\(y = a \sin (bx) + d\) などを横方向に −\(\frac{c}{b}\) だけ平行移動した形になります。正なら右、負なら左への移動です。

\(a\)が負になると中心線\(y = d\)に関して上下に反転します。\(b\)の符号を変えると、\(c\)を固定したグラフは\(y\)軸に関して左右に反転します。\(d\)は上下方向の移動量です。\(a = 0\)なら\(y = d\)、\(b = 0\)なら\(y = a \sin c + d\)または\(y = a \cos c + d\)という定数関数になります。この場合、最小の正の周期はなく、−\(\frac{c}{b}\)による説明も使えません。
