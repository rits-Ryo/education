定積分と面積・区分求積法

曲線で囲まれた領域を長方形で近似し、その和の極限と定積分を結びます。

1 定積分と面積 2 長方形の近似 3 Σと極限 4 \(x^{2}\)の具体例 5 関数と区間 6 原始関数

1. 定積分と面積

区間[\(a, b\)]で\(f(x) \ge 0\)のとき、曲線\(y = f(x)\)、\(x\)軸、2本の直線\(x = a\)、\(x = b\)で囲まれた部分の面積は定積分で表せます。初期の\(x^{2}\)、[0, 2]ではその面積は\(\frac{8}{3}\)です。

\[\int_0^2x^2\,dx=\frac83\]

境界線の上の\(a\)・\(b\)の丸いハンドルをドラッグできます。

上側：正の寄与（青） 下側：負の寄与（赤・斜線）

定積分はいつも通常の面積と等しいわけではありません。\(x\)軸より上の部分は正、下の部分は負として加えます。下側の部分の面積を\(N\)、上側を\(P\)とすると、定積分は\(P - N\)、幾何学的な面積は\(P + N\)です。幾何学的な面積は負にはなりません。

\(f\)の符号が変わる場合、\(x\)軸との交点で区間を分け、各部分の定積分の絶対値を加えると通常の面積になります。たとえば\(x^{2} - 1\)の[−2, 2]では、−1と1で区間を分けます。

2. 長方形で曲線の領域を近似する

初期例は\(f(x) = x^{2}\)、[0, 1]、\(n = 4\)です。区間を\(n\)等分し、各小区間の右端の関数値を長方形の高さにします。\(n\)を増やすと幅が小さくなり、長方形の形が曲線に近づきます。

紫の輪郭が長方形、紺の実線が曲線です。赤い長方形の寄与は負です。境界線\(a\)・\(b\)はドラッグできます。

長方形が\(x\)軸より下にあるときは、その高さ\(f(x_{k})\)を負として計算します。したがって\(S_{n}\)は符号付きの和です。各長方形の幾何学的な面積を単純に足したものではありません。

比較モードでは薄い色の曲線領域と半透明の長方形を重ねます。輪郭のずれが近似のずれです。表示した|\(S_{n} - I|\)は符号付きの和の差であり、図のはみ出し・不足の面積の合計とは限りません。

3. 長方形の和をΣと極限で表す

  1. 区間を\(n\)等分する

    \[\Delta x=\frac{b-a}n\]

    \(n\)は正の整数です。\(a\) < \(b\)のとき、各長方形の幅\(\Delta x\)は正になります。

  2. 右端を高さに使う

    \[x_k=a+k\Delta x\quad(k=1,2,\ldots,n)\]

    \(k\)番目の長方形の符号付き面積は\(f(x_{k})\Delta x\)です。

  3. すべての長方形を足す

    \[S_n=\sum_{k=1}^nf\left(a+\frac{k(b-a)}n\right)\frac{b-a}n\]

    Σは、\(k = 1\)から\(n\)までの各項を足す記号です。

  4. \(n\)を限りなく大きくする

    \(f\)が[\(a, b\)]で連続なら、\(n\)を大きくして\(\Delta x\)を0に近づけると、この和は定積分に近づきます。有限の\(n\)での\(S_{n}\)と、その極限値は区別します。

    \[\lim_{n\to\infty}S_n=\int_a^bf(x)\,dx\]

特に[0, 1]では\(\Delta x = \frac{1}{n}\)、\(x_{k} = \frac{k}{n}\)となります。

\[\lim_{n\to\infty}\frac1n\sum_{k=1}^nf\left(\frac kn\right)=\int_0^1f(x)\,dx\]

ここでは[0, 1]上で連続な関数に対する、等分・右端の高さによる高校数学の区分求積法を扱います。

4. \(x^{2}\)の[0, 1]を式で求める

\(k\)番目の長方形の高さは(\(\frac{k}{n})^{2}\)、幅は\(\frac{1}{n}\)です。第2章の\(n\)と同じ分割数を使って、この具体例の数値も更新します。

\[\begin{aligned}S_n&=\frac1n\sum_{k=1}^n\left(\frac kn\right)^2\\&=\frac1{n^3}\sum_{k=1}^nk^2\\&=\frac1{n^3}\frac{n(n+1)(2n+1)}6\\&=\frac{(n+1)(2n+1)}{6n^2}\\&=\frac13+\frac1{2n}+\frac1{6n^2}\end{aligned}\]

平方の和の公式 ∑\(k^{2} = n(n + 1)\frac{2n + 1}{6}\) を使いました。最後の式で\(n\) → ∞とすると、\(\frac{1}{2n}\)と\(\frac{1}{6n^{2}}\)は0に近づきます。

\[\lim_{n\to\infty}S_n=\frac13=\int_0^1x^2\,dx\]

この例では、\(x^{2}\)が[0, 1]で増加するため、右端の高さを使う長方形は曲線の領域を上から近似します。誤差\(\frac{1}{2n} + \frac{1}{6n^{2}}\)は\(n\)とともに減ります。しかし一般の関数で、分割数を増やすたびに近似値が必ず同じ側から単調に近づくとは限りません。

5. 関数と積分区間の変更

第2章の操作パネルで7種類の関数と区間を変更できます。どの関数も連続で、右端の高さを使う規則は共通です。第1章の面積図は独立して操作できるので、別の区間と比較できます。

\(\sin x\)の初期区間は[0, \(\pi \)]で、角度は\(rad\)です。\(x^{3}\)の[−1, 1]では正負の寄与が相殺されて定積分は0になりますが、幾何学的な面積は0ではありません。\(x^{2} - 1\)では、−1と1を境に符号が変わります。

この教材では\(a \le b\)に制限します。\(a = b\)なら幅・定積分・長方形の和はいずれも0です。数値入力で\(a\) > \(b\)にすると警告し、最後の有効な区間の図を維持します。境界線のドラッグとスライダーはもう一方の端で止まります。

6. 原始関数を用いた計算との関係

\(F'(x) = f(x)\)となる関数\(F\)を、\(f\)の原始関数といいます。\(f\)が区間で連続で、\(F\)がその原始関数なら、定積分は両端での\(F\)の値の差で計算できます。

\[\int_a^bf(x)\,dx=F(b)-F(a)\]

\[\int_0^1x^2\,dx=\left[\frac{x^3}3\right]_0^1=\frac13-0=\frac13\]

\(x^{2}\)の[0, 1]では、曲線と\(x\)軸で囲まれた面積、長方形の和の極限、原始関数による計算が、すべて\(\frac{1}{3}\)を表します。有限個の長方形の和\(S_{n}\)そのものは\(\frac{1}{3}\)ではなく、\(n\) → ∞の極限で一致します。
