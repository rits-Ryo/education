# 定積分と面積・区分求積法

高校数学Ⅱ・Ⅲの、定積分・符号付き面積・等分した長方形の和を扱う教材です。大学数学の一般的な積分理論や、クイズ・学習管理機能は設けていません。

## 起動

VS CodeのLive Serverで `index.html` を開きます。GitHub Pagesでは数学の教材一覧からアクセスできます。追加ライブラリやビルド工程は不要です。共通CSSと共通フォントを読み込みます。

## 操作

- 第1章の面積図はx²の[0, 2]、第2章の近似図はx²の[0, 1]、n = 4から始まります。両図は独立して操作できます。
- 7種類の関数を選べます。sin xはradで、初期区間は[0, π]です。関数を変えると、その関数の初期区間になります。
- aとbはスライダー・数値入力・境界線のハンドルで変更できます。操作範囲は−2π〜2πです。
- **a ≦ bに制限しています。** 逆転する数値入力は警告し、最後の有効な図を維持します。スライダー・ドラッグでは他方の端で止めます。a = bは幅・積分・和・面積を0とします。
- nは1〜200の整数です。スライダー、数値入力、代表値のボタンで変更できます。
- 表示は「曲線のみ」「長方形による近似」「曲線と長方形の比較」の3種類です。
- 再生では現在のnから倍々に200まで増やします。一時停止・再開・速度変更・n = 4へのリセットに対応します。200から再生するとn = 1から始めます。手動で区間・n・関数を変えると停止します。
- 第4章のx²の[0, 1]の数式例は、現在のnだけを共有します。第2章で関数や区間を変えても、この具体例の関数・区間は変わりません。

## 計算方法と正確性

区間をn等分してΔx = (b − a)/n、xₖ = a + kΔxとし、右端の高さによる符号付きの和 Sₙ = Σf(xₖ)Δxを計算します。加算では誤差補償を行います。定積分は登録した原始関数に基づく解析式で計算し、長方形から推定しません。

多項式積分は短い区間での桁落ちを減らすため、bの累乗とaの累乗の差を因数分解します。sin xの積分はcos a − cos bに等しい三角関数の式を使います。幾何学的な面積は解析的な零点で区間を分け、各積分の絶対値を加えます。

多項式では有限小数の端点をBigIntの分数として扱い、短く表示できる範囲で分数を併記します。sin xではπ/2の整数倍の端点で整数の積分値を併記できます。これらの角度の認識には機械精度程度の許容差を用います。それ以外は原始関数の式と小数近似で表示します。

小数は小数点以下8桁までで、非常に小さい0でない値は指数表記です。描画は有限の標本点で曲線を近似します。塗りつぶし図そのものが厳密な面積計算ではありません。|Sₙ − I|は符号付きの和と定積分の差の絶対値であり、図形のはみ出しと不足を合わせた面積ではありません。

## ファイル構成

- `index.html`：6章の数学的説明と操作パネル。
- `style.css`：共通デザインに沿った教材専用スタイル。
- `engine.js`：関数・原始関数・積分・幾何学的面積・長方形の和・分数表示。
- `drawing.js`：SVGの座標、目盛り、領域、長方形、境界線。nのみの変更では背景の曲線・軸を再利用します。
- `script.js`：入力と状態の同期、ドラッグ、アニメーション。続く入力イベントはフレームごとにまとめます。
- `tests.js`：数学的な計算の自動テスト。
- `ui-tests.js`：DOMを模擬した入力・状態・描画要求の同期テスト。実ブラウザの描画やタッチ操作は対象外です。

## 制約と今後の改善

任意の関数入力、左端・中点の規則、グラフのピンチ拡大、はみ出し・不足の独立した塗り分けは実装していません。今回の右端の規則と符号付きの和を優先しています。今後は長方形を個別に選び、その1項の高さ・幅・寄与を拡大表示する機能を追加できます。
