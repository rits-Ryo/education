# 複素数平面と回転・乗算

数学C · 複素数平面。`index.html` を数学カタログから開きます。静的HTML/CSS/Vanilla JavaScriptと既存KaTeX 0.19.0を使用します。追加ビルド・依存はありません。

## 操作と数学的条件

z₁・z₂をドラッグまたは成分入力で動かします。加算・乗算と、乗算の伸縮・回転の段階を切り替えます。

表示範囲は積・和に合わせて自動調整し、縦横を同じ縮尺にします。thetaは回転プリセットボタンを押したとき適用されます。

結果は既存NumberDisplayで小数点以下最大3桁、微小な非零値は指数表記です。内部計算と入力を丸めません。表示の等号・近似記号を区別します。無効入力は説明を表示し、直前の有効な状態を維持します。

## ファイルと改良箇所

- engine.js：DOMを使わない数学ロジック。式や判定の変更はここから。
- tests.js：代表例・境界・未定義・内部精度の独立テスト。
- drawing.js：SVG描画と数学座標変換。ラベル配置・表示範囲の改良はここから。
- script.js：状態・入力・ドラッグ・数式の同期。
- index.html / style.css：説明と教材専用レスポンシブ表示。

ルートで `node subjects/math/complex_plane/tests.js`、全体は `python3 scripts/verify.py`。安全なプレビューはルートのscripts/README.mdに従います。実機Safari・iPad等は別途確認してください。

数値表現の範囲外を数学的な零や重解・直交と誤認しないため、極端な係数・座標では明示的に拒否、未定義または範囲外の説明を表示します。
