# 完全順列

`index.html` をブラウザで開くか、VS CodeのLive Serverで表示してください。GitHub Pagesでは数学の教材一覧からアクセスできます。ビルドや追加のライブラリは不要です。

## 内容

- 完全順列の定義、包除原理の公式、漸化式、確率の極限
- ボタンで開く包除原理と漸化式の証明
- 手紙・帽子・席替えの4つの例題と解説
- n = 0〜10 の個数・確率の計算、n ≦ 5 の完全順列一覧

計算には漸化式を使います。表示範囲の整数はJavaScriptのNumberで正確に扱えます。確率の分数は約分した正確な値、小数は小数第6位に丸めた近似値です。

## ファイルの役割

- `index.html`：説明、証明、例題。JavaScriptが無効でも読めます。
- `derangement.css`：教材固有のレイアウト。長い数式・表は横スクロールできます。
- `derangement.js`：計算関数、一覧生成、画面更新を分離しています。

共通フォントとヘッダーは既存の共通CSSを利用します。iPadなどのタッチ操作では証明・解答の見出しをタップして開閉できます。

授業では、まず3個の並びを数え、例題1から包除原理に進み、例題3・4で「ちょうど」と「少なくとも」の違いを比較できます。
