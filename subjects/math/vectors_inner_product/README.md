# ベクトルと内積 — なす角と正射影の可視化

数学C・平面ベクトルの可視化教材。初期値はa = (4, 0)、b = (3, 2)。ビルドや追加ライブラリは不要です。数学の一覧へ戻るリンクを備えています。

## 操作

A・Bのハンドルをマウスまたはタッチでドラッグします。数値入力、整数格子点スナップ、0°・45°・90°・120°・180°のプリセット、リセットにも対応します。重なった終点は左右にハンドルを分け、短い線で実際の終点に接続します。ハンドルはTabで選択し、矢印キーでも操作できます。ドラッグ中だけタッチのスクロールを抑制します。

なす角、正射影、垂線、成分の補助線、内積の計算過程を個別に切り替えられます。計算値の読み出しは切り替え後も表示します。PCは図と操作を横並びにし、800px以下では縦並びにします。SVGなので画面の密度によらず鮮明で、縦横の縮尺は等しくなります。座標の表示範囲は自動調整し、ドラッグ中は固定します。

## 数学と数値処理

- 内積はスカラー、スカラー射影は符号付きの数、正射影はベクトルとして区別。
- なす角はatan2を用いて0〜180°。零ベクトルとの角は未定義。
- a = 0の射影は未定義、b = 0かつa ≠ 0の射影は零ベクトル。
- 単位方向とスケール調整を使用し、微小なaの二乗によるアンダーフローを避けます。
- 成分は有限な数で±1000000以内。無効な入力では最後の有効状態を維持。
- 表示は最大6桁程度に丸め、微小な値は指数表記。内積が数値表現範囲より小さい場合も、非零の符号を保持する指数表示を用います。
- 入力数値の最短十進表記をBigIntによる整数演算で扱い、成分積と和の符号・零を正確に決定します。値・符号・射影は共通の内積を使用。幾何式の値もこの内積の別表現であり、独立した再乗算結果ではありません。
- |cosθ| < 10⁻¹²の非零値は「ほぼ直交」とし、厳密な0とは区別。相対的な角度の目安で、内積を0に丸める判定ではありません。表示角度が90°に丸められる場合も正負は保持します。入力時にNumberへ変換して失われた桁は復元しません。
- 余弦定理による成分公式の導出、内積と正射影の関係、零ベクトルに関する例外を本文で説明。

## ファイルとテスト

engine.jsはDOMに依存しない計算処理、drawing.jsはSVG描画、script.jsは入力とPointer Eventsの同期です。

```sh
node subjects/math/vectors_inner_product/tests.js
node subjects/math/vectors_inner_product/ui-tests.js
python3 scripts/verify.py
```

数学テストは指定された内積、角度・符号・正射影、零ベクトル、微小成分、幾何式との一致を検証。UIテストは実際の操作コードをDOMシミュレーションで実行し、数値入力・拒否・プリセット・切り替え・ドラッグ・スナップ・キャンセル・キーボード・リサイズ・リセットを検証します。実ブラウザの描画やタッチ操作の代替ではありません。

プレビューとサーバー終了はリポジトリのscripts/README.mdに従い、scripts/prepare_preview.pyを使用します。未追跡の教材ファイルは内容確認後にindex.html、style.css、engine.js、drawing.js、script.jsをそれぞれ--includeで指定してください。
