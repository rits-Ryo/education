2. 正射影から内積へ

ベクトルの大きさは |a| = √(a₁² + a₂²)、|b| = √(b₁² + b₂²) です。零ベクトルでない2つのベクトルのなす角θは、0°から180°までの小さい方の角です。

a ≠ 0 のとき、Bからaを含む直線に下ろした垂線の足をHとします。OHはbのa方向への正射影ベクトルです。Hは線分OAの外に出ることもあります。

\[\begin{aligned}s&=|\vec b|\cos\theta=\frac{\vec a\cdot\vec b}{|\vec a|}\\\overrightarrow{OH}&=\operatorname{proj}_{\vec a}\vec b=\frac{\vec a\cdot\vec b}{|\vec a|^2}\vec a\end{aligned}\]

スカラー射影は符号付きの数、正射影は向きを持つベクトルです。OHの大きさは |s| です。鋭角ではs > 0でOHはaと同じ向き、直角ではs = 0でOHは零ベクトル、鈍角ではs < 0でHはOを挟んでaの反対側に現れます。

\[\vec a\cdot\vec b=|\vec a||\vec b|\cos\theta=|\vec a|\left(|\vec b|\cos\theta\right)=|\vec a|s\]

内積は「aの大きさ × bのa方向への符号付きの射影の長さ」というスカラーです。図の紫の矢印と、その符号付きの長さを数式に対応させると、内積の正・零・負の意味が分かります。

a = 0ならaの方向がないため正射影は定義されません。b = 0かつa ≠ 0なら正射影は零ベクトルです。どちらかが零ベクトルならθとcosθは定義されませんが、内積は0です。この場合の射影は成分公式から計算します。

3. 成分による内積とその導出

\[\begin{aligned}\vec a&=(a_1,a_2),\quad\vec b=(b_1,b_2)\\\vec a\cdot\vec b&=a_1b_1+a_2b_2\end{aligned}\]

O、A、Bが作る三角形に余弦定理を用いると（同方向・反対方向ではその極限としても同じ式が成り立ちます）、

\[|\vec a-\vec b|^2=|\vec a|^2+|\vec b|^2-2|\vec a||\vec b|\cos\theta\]

一方、座標から距離を求めて展開すると、

\[\begin{aligned}(a_1-b_1)^2+(a_2-b_2)^2&=|\vec a|^2+|\vec b|^2\\&\quad-2(a_1b_1+a_2b_2)\end{aligned}\]

両式を比較して |a||b| cosθ = a₁b₁ + a₂b₂ を得ます。零ベクトルを含む場合にも成分公式は使え、内積は0となります。

初期値では (4, 0)・(3, 2) = 4 × 3 + 0 × 2 = 12。正射影は (3, 0)、スカラー射影は3なので、幾何学的にも4 × 3 = 12です。内積の表示と符号は、同じ成分計算の値を基準にします。cosθ・射影もこの内積から求め、幾何式は同じ数学的な値を別の形で示しています。大きさやcosθの表示は丸めているため、画面上の数だけを再び掛けると末尾に差が出る場合があります。

4. 内積と直交条件

零ベクトルでない2つのベクトルについて、|a||b| > 0なので、

\[\begin{aligned}\vec a\perp\vec b&\iff\theta=90^\circ\iff\vec a\cdot\vec b=0\\&\iff a_1b_1+a_2b_2=0\end{aligned}\]

θ < 90°なら内積は正、θ > 90°なら負です。どちらかが零ベクトルの場合、内積0からなす角90°とは結論できません。

入力欄とドラッグで得た数の十進表記を基準に、成分の積と和を整数演算で求めます。この内積が厳密に0の場合だけ「直交」と表示します。|cosθ| < 10⁻¹² の非零の内積は「ほぼ直交」と表示し、正負は保持します。この基準は |a・b| / (|a||b|) に対応する相対的な目安で、小さな内積を0に置き換えるものではありません。角度が表示上90°に丸められても、厳密な直交とは限りません。入力時に数値として保持できなかった桁は復元できません。90°のプリセットは b = (0, 4) を直接設定します。
