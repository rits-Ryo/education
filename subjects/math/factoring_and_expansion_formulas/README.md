# 因数分解・展開の公式

`factoring_and_expansion_formulas.html` を開いて利用します。数学の教材一覧にも登録されています。HTMLとCSSだけで動作し、外部ライブラリやビルドは不要です。

基本・三乗・応用の13公式を掲載しています。「導出を見る」を押すと途中の計算が開き、もう一度押すと閉じます。キーボードでも操作できます。長い式は横にスクロールして確認してください。

公式を追加するときはHTMLの `article.formula-card` を複製し、公式・注意点・例を変更します。導出は `details` 内の `ol.derivation` に段階ごとに記載します。数式の累乗には `sup` を使用します。このフォルダーには、この教材に必要なファイルだけを配置してください。

掲載公式と導出は、35組の式を多項式として展開して係数が一致することを確認しています。ブラウザの目視確認とiPad実機確認は未実施です。
