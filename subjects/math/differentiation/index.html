微分 — 接線の傾きと導関数

2点を結ぶ直線の傾きから、各点の接線の傾きへ。その変化が導関数のグラフになります。

1 平均変化率 2 接線 3 導関数 4 増減と極値 発展 微分可能性

全章で共通の関数と点\(P\)

点\(P\)の位置は全章で連動します。各グラフの\(P\)もドラッグできます。\(\sin \)と\(\cos \)の\(x\)は弧度法（\(rad\)）です。数値は小数点以下最大3桁の近似表示、関数と導関数の式は解析式です。

1. 平均変化率から微分係数へ

曲線上の2点 \(P(a, f(a))\)、\(Q(a + h, f(a + h))\)を結ぶ直線を割線といいます。横の変化量は\(h\)、縦の変化量は\(f(a + h) - f(a)\)なので、割線の傾きはその比です。\(h\)が負なら\(Q\)は\(P\)の左側になります。

\[\text{平均変化率}=\frac{f(a+h)-f(a)}h\quad(h\ne0)\]

\(P\)と\(Q\)はドラッグできます。\(Q\)のドラッグは\(h\)を−1〜1に制限します。\(P\)と\(Q\)が重なる場合はスライダーで\(h\)を変更できます。

\[f'(a)=\lim_{h\to0}\frac{f(a+h)-f(a)}h\]

\(h\)を0に近づけるとは、\(h\)を0そのものにするのではなく、0でない値のまま、正と負の両側からその絶対値を小さくすることです。そのとき平均変化率が同じ1つの有限の値に近づけば、その極限を微分係数\(f'(a)\)といいます。極限とは、\(h\)を十分0に近づけることで、平均変化率をその値にいくらでも近づけられることです。

\(h = 0\)を直接代入すると分子も分母も0となり、平均変化率は定義されません。微分係数は\(\frac{0}{0}\)の計算結果ではなく、極限値です。割線の傾きの極限が接線の傾きになり、左右からの極限が一致しない点では微分係数は存在しません。

\(x^{2}\)の場合の式の変形

\[\begin{aligned}\frac{(a+h)^2-a^2}h&=\frac{2ah+h^2}h\\&=2a+h\quad(h\ne0)\end{aligned}\]

\(h\)を0に近づけると2\(a + h\)は2\(a\)に近づきます。したがって \(f'(a) = 2a\) です。\(h\)を約分できるのは\(h \ne 0\)の場合だけです。

2. 接線の傾きと導関数

点\(P\)を通り、傾き\(f'(a)\)を持つ直線が接線です。点と傾きから、接線の方程式は次のように表せます。

\[y=f'(a)(x-a)+f(a)\]

\(f'(a)\)は「特定の位置\(a\)での微分係数」という数値です。一方、位置を変数\(x\)として各点の微分係数を対応させた関数\(f'(x)\)を導関数といいます。導関数は、元の関数の各点における接線の傾きを表す関数です。

3. 元の関数と導関数のグラフ

\(y = f(x)\)

\(y = f'(x)\)

\(P(a, f(a))\)と\(R(a, f'(a))\)の\(x\)座標は同じ\(a\)です。元の関数の接線の傾きが、そのまま導関数上の\(R\)の\(y\)座標になります。初期の\(f(x) = x^{2}\)では、\(f'(x) = 2x\)なので、\(a\) < 0で傾きは負、\(a = 0\)で0、\(a\) > 0で正です。

4. 導関数と増減・極値

ある区間のすべての内点で\(f'(x)\) > 0なら、その区間で\(f\)は増加し、\(f'(x)\) < 0なら減少します。図では増加区間を緑の実線、減少区間を赤の破線で区別します。下の一覧にも区間と符号を表示しています。

金色の輪は停留点です。導関数のグラフでは同じ\(x\)座標の\(y = 0\)に表示します。

\(f'(x) = 0\)となる点を停留点といいます。導関数の符号が正から負に変わると極大、負から正に変わると極小になります。極値はその点の近くでの大小を表し、定義域全体での最大・最小とは区別します。

\(f'(x) = 0\)だけでは極値とは限りません。\(f(x) = x^{3}\)では\(f'(x) = 3x^{2}\)です。\(x = 0\)で導関数は0ですが、左右で正のままで、関数は増加を続けるので極値ではありません。\(f(x) = x^{3} - 3x\)では\(f'(x) = 3(x - 1)(x + 1)\)となり、\(x = -1\)で正から負（極大値2）、\(x = 1\)で負から正（極小値−2）へ変わります。

表示範囲の端はグラフを切り取った位置であり、定義域の端ではありません。選べる6つの関数の定義域は実数全体です。

発展：連続でも微分できない関数

\(f(x) = |x|\)は\(x = 0\)で連続ですが、微分可能ではありません。\(a = 0\)での平均変化率は |\(h|/h\) です。\(h\) > 0では1、\(h\) < 0では−1となり、左右の極限が一致しません。\(f'(0)\)は未定義です。

\[\lim_{h\to0^-}\frac{|h|}h=-1,\qquad\lim_{h\to0^+}\frac{|h|}h=1\]

\(f'(0)\)：未定義。傾き1と−1の直線は左右の割線の極限であり、1本の接線ではありません。

微分可能であれば連続ですが、連続であることだけでは微分可能とは限りません。図のような折れ曲がりでは、接線の傾きが1つに定まりません。
