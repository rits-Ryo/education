# 微分 — 接線の傾きと導関数

平均変化率、微分係数、接線、導関数、増減と極値を図で結ぶ静的教材です。問いかけ・クイズ・得点・学習管理機能はありません。

## 起動方法

VS CodeのLive Serverで `index.html` を開くか、GitHub Pagesの数学の教材一覧から開きます。追加ライブラリとビルド工程は不要です。サイト共通のCSSとBIZ UDPゴシックを利用します。

## 操作

- 共通の関数選択では、x²、x³、x³ − 3x、−x² + 4x、sin x、cos xを選べます。関数変更時はa = 1、h = 0.8に戻ります。
- aはスライダー、数値入力、グラフ上のPのドラッグで変更できます。全章のPと導関数上のRが同期します。
- hは−1〜1です。Qをドラッグして変更できます。PとQが重なったときはhのスライダーを使ってください。
- 割線・接線・増減の色分け・停留点を表示切り替えできます。
- 「hを0へ近づける」は現在のhの符号を保って0へ接近し、|h| = 1e−8で止まります。h = 0は入力できますが、平均変化率は未定義です。
- 点Pの再生はaの操作範囲の右端まで移動して停止します。一時停止・再開・リセット・速度変更に対応します。
- 手動操作や関数変更ではアニメーションを停止します。hの接近とPの再生は同時には行いません。ページを非表示にしても停止します。
- 三角関数のxはradです。関数ごとにaの操作範囲とグラフ範囲を設定し、Qが表示範囲に入る余裕を設けています。

## 数学的な設計

導関数は解析式を管理し、数値微分で推定していません。接線はその導関数の値と点Pから求めます。停留点は導関数の解析的な零点を使い、左右の符号で極大・極小とそれ以外を区別します。表示範囲の端は極値として判定しません。

平均変化率はh ≠ 0に対してのみ計算します。多項式は展開・約分した式を使い、sin・cosは加法定理とsin(h/2)/(h/2)を使います。小さなhではこの比の級数展開を用い、値の引き算による桁落ちを避けます。極端に小さいhでは浮動小数点計算でQとPが同じ座標になることがありますが、平均変化率は安定した式で計算します。

三角関数の解析的な零点では浮動小数点の残差を機械精度程度の許容差で0に補正します。その他の小さな数を一律に0にはしません。数値表示は小数点以下2桁まで、小さな0でない値は指数表記です。計算の精度は表示の丸めと分離しています。

|x|の例は発展セクションとして独立し、f′(0)を未定義として表示します。左右の極限直線を1本の接線として扱いません。

## ファイル構成

- `index.html`：解説・操作・グラフ領域。
- `style.css`：教材固有のレスポンシブスタイル。
- `engine.js`：関数、導関数、平均変化率、接線、増減の計算。
- `drawing.js`：SVG、座標変換、自動目盛り、曲線と直線の描画。
- `script.js`：入力、ドラッグ、再生と画面の同期。
- `tests.js`：計算処理の自動テスト。

SVGの曲線は有限の標本点を結ぶ表示です。増減・停留点の判定は描画の標本探索ではなく解析式に基づきます。

## テスト

```sh
node subjects/math/differentiation/tests.js
node subjects/math/Quadratic_function/tests.js
node subjects/math/trigonometric_functions/tests.js
```

平均変化率、6関数の導関数、接線、増減、極値ではない停留点、|x|、h = 0、非常に小さいh、零点と不正入力を確認します。

ブラウザで教材を開き、関数変更、P・Qのドラッグ、hの正負と0、再生・停止・リセット、表示切り替えを確認してください。PCでは2つの連動グラフを横並びに、幅800px以下では縦並びにします。iPad・スマートフォンでは指によるドラッグとスクロールの分離を確認してください。
