# 二項分布と期待値・分散

数学B · 確率分布。`index.html` を数学カタログから開きます。静的HTML/CSS/Vanilla JavaScriptと既存KaTeX 0.19.0を使用します。追加ビルド・依存はありません。

## 操作と数学的条件

n・p・kを調整して理論分布と累積確率を表示します。nを減らすとkは新しい上限に合わせます。

n≤60。確率質量の和・期待値・分散のテスト許容差は10⁻¹²。累積は丸め前の確率を加算します。

結果は既存NumberDisplayで小数点以下最大3桁、微小な非零値は指数表記です。内部計算と入力を丸めません。表示の等号・近似記号を区別します。無効入力は説明を表示し、直前の有効な状態を維持します。

## ファイルと改良箇所

- engine.js：DOMを使わない数学ロジック。式や判定の変更はここから。
- tests.js：代表例・境界・未定義・内部精度の独立テスト。
- drawing.js：SVG描画と数学座標変換。ラベル配置・表示範囲の改良はここから。
- script.js：状態・入力・ドラッグ・数式の同期。
- index.html / style.css：説明と教材専用レスポンシブ表示。

ルートで `node subjects/math/binomial_distribution/tests.js`、全体は `python3 scripts/verify.py`。安全なプレビューはルートのscripts/README.mdに従います。実機Safari・iPad等は別途確認してください。

pが0と1の間にあるとき、表現範囲を下回る正の確率はその旨を表示し、数学的な0とは区別します。
