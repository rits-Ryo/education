# 最大・最小ラボ

高校数学の二次関数と閉区間の最大・最小を、頂点・端点・中点の関係から学ぶ教材です。`max_min.html` が本体、`index.html` は本体を開く入口です。外部依存、CDN、ビルド、インストールは不要です。

## 起動

GitHub Pagesで利用する場合は <https://rits-ryo.github.io/education/> の教材一覧から「最大・最小ラボ」を選んでください。以下は手元で開発・確認する場合の手順です。

1. VS Codeでこのフォルダを開きます。
2. Live Server拡張機能を使用し、`max_min.html` を右クリックして「Open with Live Server」を選びます。
3. またはブラウザで `max_min.html` を直接開けます（すべてのファイルを同じフォルダに置いてください）。

## iPadで使う

PCとiPadを同じWi-Fiに接続します。Live ServerがLANからアクセスできる設定になっていることを確認し、iPadのSafariで `http://PCのLAN内IPアドレス:5500/max_min.html` を開きます。ワークスペース全体をサーバーのルートにした場合は `/Quadratic_function/max_min.html` です。ポート番号はLive Serverの表示に合わせてください。Windowsのファイアウォールでローカルネットワークからの接続が許可されている必要があります。学校Wi-Fiの端末間通信制限がある場合はネットワーク管理者に確認してください。

横向きでも縦向きでも利用でき、狭い画面では縦に並びます。スライダー、数値入力、境界比較、拡大縮小ボタンはタッチで操作できます。グラフは指でドラッグできます。ピンチ操作は未実装です。実機のiPad Safariでの最終確認は未実施です。

## 数式入力

関数、左端、右端を入力し「式を適用」を押してください。閉区間の両端が等しい場合も扱えます。左端が右端より大きい場合は警告します。

- 例：`x^2`、`(x-a)^2`、`x^2-2*a*x+3`、`-x^2+a*x+1`、`a*x^2+b*x+c`、`x^3-3*a*x`、`abs(x-a)`、`sin(x)`、`sqrt(x+2)`。
- 四則演算、累乗 `^`、括弧に対応。`2x`、`3(x+1)` のような暗黙の乗算も可能です。文字同士は `a*x` と明示してください。
- `sin`, `cos`, `tan`, `abs`, `sqrt`, `exp`, `log`, `ln`, `floor`, `ceil` を評価できます。`log` と `ln` は自然対数、三角関数はラジアンです。
- 定数は `pi`（または `π`）、`e`。変数は小文字1文字。`x` は独立変数、その他はパラメータです。端点に `x` は使えません。
- パラメータは自動生成され、数値を直接入力できます。範囲と刻み幅を変更できます。直接入力はスライダー範囲外でも可能です。リセットは値を0に戻し、範囲設定は維持します。
- 入力は専用の構文木で解析します。`eval` / `new Function` は使用しません。

## 授業での活用

問題Aでは `a = -1, 0, 1, 2, 4, 5` を順番に比較します。最小値は頂点が区間の外に出る時、最大値は頂点が区間の中点を通過する時に位置が変わります。右側の説明を読む前に予想させると効果的です。

境界カードの「直前／境界／直後」で値と達成位置を比較できます。問題Bでは区間の移動、問題Cでは上に凸の場合の最大と最小の役割の入れ替わり、問題Dでは定義域が成立しなくなる場合も確認してください。複数パラメータの式では、境界の対象を選び、他の値を固定して比較します。

グラフの灰色は表示範囲内の関数、青は定義域内、赤は最大、緑は最小、紫は頂点と対称軸です。同じ点が最大かつ最小の場合は赤の外側の輪と緑の内側の輪で表示します。定数関数は全区間で達成と表示します。スライダーを動かす間は表示範囲を固定し、見切れた時は「表示をリセット」で合わせてください。

## 正確性と制限

- 二次以下の多項式として認識できる式は係数から解析します。二次係数0の一次／定数への退化にも対応します。頂点と区間、頂点と中点の比較で達成位置を求めます。表示値はJavaScriptの浮動小数点で丸められ、分数や根号の厳密な記号表示ではありません。
- 二次関数の境界は `B+2AL=0`, `B+2AR=0`, `B+A(L+R)=0`, `A=0`, `R-L=0` から導きます。選択パラメータの二次以下の多項式になれば解析します。それ以外は設定範囲を512分割し符号変化を探索する数値候補です。接する根などは見落とし得ます。常に成立する等式は境界カードを生成しません。二次関数の一般的な条件表と現在の説明を併用してください。
- 一般の関数は2048分割し、局所的な候補を黄金分割探索で改善します。複数の達成位置も候補として表示します。大域的な最大・最小やすべての達成位置は保証しません。細かい振動、狭い山や谷は見落とし得ます。
- 対応する式に区間演算を行い、全区間で実数として定義され連続となることを保守的に確認します。確認できない場合は最大・最小の表示を消して警告します。`1/(x-0.12345)` のようにサンプル点から外れた極も、分母が0を含む区間であることから警告します。
- `tan`, `floor`, `ceil` は数式として入力・描画できますが、一般の区間の連続性判定には対応しないため極値を判定しません。`1/(x-x+1)` のように区間演算で安全性を証明できない連続な式も警告する場合があります。一般の関数の厳密な場合分けは生成しません。
- 非常に大きい値・小さい値、病的な式、浮動小数点の限界を超える計算は対象外です。灰色の描画も有限分割の近似であり、未定義点の完全な表示ではありません。

## ファイルと検証

`style.css`：レイアウト、`script.js`：入力・スライダー・グラフ・説明、`engine.js`：安全な式解析・計算、`tests.js`：計算の回帰テスト。

Node.jsがある場合、`node tests.js` で実行できます。頂点が左右・内部・端点、両端の等値、負の係数、一次・定数への退化、1点の区間、逆転区間、入力エラー、複数パラメータ、未定義点、一般の関数、境界方程式を検証しています。

ブラウザUIとiPad実機の描画・操作は未検証です。この環境のブラウザ検証ツールがローカルファイルURLを拒否したため、ブラウザの目視確認は実施できませんでした。授業導入前にLive Serverと実機で確認してください。
